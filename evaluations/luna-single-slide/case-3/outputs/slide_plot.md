# スライド・プロット

- 対象読者：3D形状のニューラル表現を学び始めた読者。
- 中心質問：場による表面表現は何を共通化し、3つの代表モデルはどこが違うか。
- 回答：点座標に対する場の値から等値面・決定境界を表す。Occupancy Networks と IM-NET は内外を分ける分類場を使い、DeepSDF は符号付き距離場を使う。場の意味に加え、再構成・潜在形状表現・生成デコーダという用途にも違いがある。
- T：表面を「場の境界」として表す。
- B：原図で連続決定境界と離散出力表現を対比し、式と下段のモデル別要約で場の意味・用途を説明する。
- Bottom：共通点は「連続場→境界抽出」。違いは場の値と形状を得る経路。
- Figure：Mescheder et al. Fig. 1 原図。左から voxel / point / mesh / occupancy network の出力表現を示す。
- Next：連続関数からどの密度でサンプリングし、メッシュへ変換するか。
- 境界：連続場を任意位置で評価できる性質と、有限解像度で抽出したメッシュの幾何精度を区別する。
