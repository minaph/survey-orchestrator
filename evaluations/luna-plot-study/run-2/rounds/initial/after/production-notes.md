# 制作メモ・未解決事項

## 調査の範囲と方法

- 入力は本ワークスペースの`corpus/README.md`、`corpus/bibliography.json`、`corpus/papers/`にある10論文のPDFおよびテキスト抽出に限定した。
- 方法は提供文献を対象とする叙述的・批判的サーベイ。検索データベース・検索式・採否フローを伴う系統的レビューではないため、網羅性は主張しない。
- 制作手順・プロット要件は`SKILL.md`と`references/storyline-plot.md`、`survey-methods.md`、`evidence-model.md`、`survey-design-analysis.md`、`research-slide-writing.md`、`review-rubric.md`、`figure-extraction.md`、`evidence-visual-contract.md`を参照した。
- 評価条件が違うベンチマークの得点を一つの順位へ統合しない。原論文の報告と、本サーベイの方式選択解釈をスライド内で区別する。

## 根拠の役割対応

| 論文 | プロットでの役割 | 適用範囲・留保 |
|---|---|---|
| Lost in the Middle | 情報位置による長文脈利用のムラ | 評価したQA・キー値課題内の結果。すべてのモデル・問いへ一般化しない |
| RULER | 公称窓・NIAHを超える長さ／課題別評価 | 合成課題ストレステスト。実世界性能の直接推定ではない |
| LOFT | 長文脈モデルが一部ツール型タスクで競合する可能性 | 課題設定・プロンプト依存。SQL様推論の弱点も報告 |
| Self-Route | LCとRAGの性能・トークン費用比較、問い別ルーティング | データセット・モデル・トークン費用の範囲内。自己判定の校正と全費用は別途必要 |
| LaRA | 条件別の直接比較、位置・タスク・長さの効果 | 2326問・4種QAと評価モデル構成の範囲。本文の差分表記を図表と照合する |
| Long-Context LLMs Meet RAG | 長文脈生成器に対する取得量・hard negative・順序の課題と改良 | 各手法の評価設定固有。独立したRAG対LC総合比較ではない |
| OP-RAG | 順序保持RAGと取得件数の最適点 | 指定データセット・モデル・指標の結果。トークン数と実コストを同一視しない |
| LongCite | 細粒度引用・検証可能性の設計 | 引用付き長文QAが焦点。引用の支持妥当性は別途評価する |
| LongBench v2 | 現実的・深い長文理解課題の難しさ | RAG対LCの方式比較ベンチマークではない |
| BERGEN | RAG比較の設定差と再現可能評価 | ライブラリ・QA評価基盤として参照し、LCとの直接比較結果とは扱わない |

## 残る限界・未解決点

- 価格・GPU時間・レイテンシ・インデックス構築や更新費用を全論文で同一尺度比較できる根拠は揃っていない。Self-Route等の入力トークン比を総費用と読み替えない。
- 出典の「引用あり」と、個々の主張が出典に支持されていること、必要な根拠を網羅したことは別の品質である。運用先では引用正確性・支持率・根拠再現率を追加計測する。
- 自己ルーティングの誤判定率・校正・再試行費用は、採用するモデル／業務分布で検証が必要。
- 2025年のLaRA、LongCite、LongBench v2を含むが、コーパスは最新研究全体ではない。モデル能力・価格・API仕様の更新を反映した実運用判断には追加調査が必要。
- 評価対象に英語・中国語や合成タスク等が含まれ、日本語の専門文書集合へ直接一般化できない。日本語・ドメイン固有コーパスでの比較実験が必要。
- 原図候補の実ファイル抽出、権利・利用経路の確定、実スライドのレンダリング確認は未実施。`plot.md`は制作可能な詳細プロットであって、完成スライドや図抽出台帳ではない。
