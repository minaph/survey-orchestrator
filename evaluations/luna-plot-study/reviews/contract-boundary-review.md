# 構成評価と視覚制作契約の境界レビュー

## 指摘と判断

**[P2・制作への無条件引継ぎを阻害] Run 1／3のSelf-Route紹介ページに置く文章由来の自作フローは、固定版の視覚制作契約と整合していません。** 意味的に正しい説明であること、原図と自作図を区別したことだけでは使用を許可できません。

- 対象: `run-1/rounds/discussion-2/after/plot.md:99` と `run-3/rounds/discussion-2/after/plot.md:101`。
- 根拠: 評価時の固定版 `snapshot/references/reconstruction-review.md:17` は「文献紹介スライドでは、サーベイ作成者による再構成を使いません」とし、文章から作った図も明示的に含めます。`:107`もキャプションでは文献紹介の再構成を許可できないとしています。実際のページはSelf-Routeの手法・条件・結果を紹介し、図も同論文§4.2の手順の説明です。独自の資料間統合という実際の役割にはなっていません。
- 影響: 現案のまま自作フローを実装することは承認できません。「本発表の説明用再構成」「手法説明の再構成」というラベルを追加しても、この禁止を解除できません。形式上の分類変更だけで独自統合へ移すこともできません。

**追加のLuna往復を、今回の構成能力評価の終了条件にする必要はありません。** ただし、評価の終了と、当該視覚計画の許可・制作準備完了を同一視しないことが条件です。「問題なしの完成プロット」「全制作契約に適合し、そのままG5へ進める」とする無条件の承認は、この発見に照らして限定します。

## 終了承認の範囲

ユーザーの依頼は「枚数や構成なども独自に考えさせ」「それぞれと壁打ち」「細部まで書き込んだ壊れやすい指示ではなく…一般性のある妥当な改善」です。監督者の今回の依頼は「追加のLuna往復が必要な中心的問題か、G5引継ぎ時の許可確認残件として明記可能か」を判断し、「内容を完成扱いしつつ矛盾を隠す報告」を避けることです。

`protocol.md:29` は問いと結論、比較・引用・推論、ページの役割と根拠配置を構成評価の終了基準とし、`:31` は「プロットの完成は、スライド実装・投影確認・正式公開検査の完了とは別」としています。

今回の自作フローを未許可として保留しても、Self-Routeの二段階手法はBに記載済みで、性能・費用は原Fig.1／Table 1へ辿れます。ルーティングが有用となる条件や校正の限界も文章にあります。図の使用許可を解消するために中心回答、比較の集計、節順序を再設計する必要はありません。したがって、構成・論証の評価を終了したという判断は維持できます。

一方、固定版 `snapshot/references/storyline-plot.md:133` は再構成候補へ再構成レビューを適用し、`:135` は実際の役割と要件の正本を同契約とします。`snapshot/references/reconstruction-review.md:132` は配置前の許可判断を、`:134` はG5前の確認を要求します。図の許可は、公開直前まで放置できる単なる見た目の検査ではありません。

終了承認は次のように区別します。

| 判断対象 | 判定 |
| --- | --- |
| protocolに基づく構成・論証の評価終了 | 維持する。追加のLuna往復は必須にしない |
| 評価記録としてのfinal plotの保存・mainへのマージ | 本レビューの境界と残件が追跡可能に併記される範囲で承認 |
| 当該自作フローの使用許可 | 未承認。現契約下の文献紹介ページでは禁止 |
| 現案のままG5で当該図を実装すること | 承認しない。G5前のG4-Vで局所修正が必要 |
| 全制作契約適合、完成スライドの本番公開・運用 | 今回の承認には含めない |

## 引継ぎで残す内容

既存の制作メモまたは引継ぎ記録に、対象ページと自作図、禁止の根拠、現案のまま実装しないこと、G5前に再確認することを明記すれば足ります。新しい必須schema、全ページ監査、追加の公開ゲートは不要です。

残件は単に「図の許可を後で確認」とするのではなく、**「文献紹介の役割のまま文章由来の自作フローを使う案は現契約で不可。中心の意味内容は確認済みだが、視覚計画はG4-Vで局所修正してからG5へ渡す」**と記録します。修正方法は原図・文章・表で説明する経路、または実際の役割を独自統合として再検討する経路から、制作担当が既存契約に従って判断します。本レビューは差替図や完成構成を指定しません。

前回の意味確認では、原Fig.1をフローと誤読した問題を訂正し、原図と説明用再構成の帰属を分けたことを評価しました。しかしその判定は、文章由来の再構成に対する役割別の使用禁止を解消したものではありません。今回、この未確認だった制作契約への適合を残件として明示し、以前の承認を上記の範囲へ限定します。意味的な改善を、制作契約適合の改善として報告しません。
