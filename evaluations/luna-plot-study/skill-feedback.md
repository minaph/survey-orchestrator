# 詳細プロット評価からのスキル改訂

## 採用範囲と根拠

ユーザーの依頼は「学術的な問いと約10論文をゼロから作成」「3つのluna highにお題・論文・skillのみで詳細プロット」「各々壁打ち」「全3件終了後skillへ」であり、改善では「細部まで書き込んだ壊れやすい指示」ではなく「一般性のある妥当な改善」を重視していました。本メモは全3件の独立レビューによる終了判断後に作成しています。改訂は現行の `SKILL.md` と `references/storyline-plot.md` に限り、固定入力のsnapshot、各runの入力・成果・履歴は変更していません。

## 既存説明と採用した変更

既存定義の再利用と、情報源の報告・調査側の導出・判断の区別には `conceptual-modeling` を適用しました。`ai-prose-argument-audit` の主張・根拠・推論・範囲の区別で、具体的比較が判断へつながる箇所と、候補の列挙で止まる箇所を分けました。レビュー結果上、Run 1の構成は `GOOD`、Run 2・3の中心比較の未確定箇所は `BAD-argumentatively-weak` に相当します。この分類は生成元の判定ではなく、当該箇所の論証上の機能についての診断です。`evidence-based-writing` に沿い、必要な条件を保ち、注意書きの増設より読者が得る判断を説明しました。

| 既存の説明・定義 | 採用した最小変更と理由 |
| --- | --- |
| [RRM](../../references/rrm.md)は題名・要旨等で関連を見定め、対象・方法・比較・結果へ戻る読解を既に説明しています。[根拠モデル](../../references/evidence-model.md)は報告・研究・根拠・主張を分けています。 | プロットのG4の入口に、論文の役割・回答を決めるときに、問いを変え得る研究内比較・反証・条件へ戻る説明を置きました。一論文の背景と直接比較の両役割を認め、論文全体を要旨や主目的のみで一括分類する失敗に対応します。 |
| プロットのG4-Vは図の軸・注記・条件や方法図と結果図を確認し、G4-Pは本文と図の関係を検討します。 | 中心結論の比較対象・操作・観察と図・必要なパネルの対応を、制作へ渡すまでに確定する順序を明示しました。図番号の候補だけを引き渡し、制作側で論証を選び直す負担を減らします。補助図の切り出し・配置は制作判断として残せます。 |
| 根拠モデルは量の意味・集計水準・情報状態、RRMは結果と調査側の解釈を区別します。 | 既存のG4の矛盾保持の説明へ、原典内の値の対応と原因未確定の不一致、再計算と著者の集計方法、異種指標の集約範囲の区別を補いました。数値の一致を原因確定へ読み替える失敗に対応します。 |
| プロットは正本への参照を優先し、共通根拠の改訂時に読者表現と展開値を更新します。 | 同じ段落で、影響する見出し・本文・図指定・結論、制作メモの現行判断・残件を合わせることを明示しました。変更前の内容は履歴と区別し、解決済み判断を後続担当者が再開する混乱を減らします。 |
| [研究紹介の執筆](../../references/research-slide-writing.md)は中心命題、原典抽出、図選択、具体的観察、条件付き評価を既に扱います。 | 本文を増設せず、SKILLの参照条件を詳細プロットの執筆段階から適用するよう変更しました。SKILLのG4-Pの要約も中心比較と図の観察の確定へ合わせました。 |

架空の小例は、説明あり・なしの比較から直後の正答率と翌週の保持の観察を読み、限定した判断へ進む関係を示します。実験の数値や特定論文の正解構成を埋め込まず、読者が採用理由と次の検証を理解する効用を説明しています。

## 採用しなかった要求と境界

- 新schema、必須欄、独立した品質門、全論文同量の紹介は追加しません。既存の根拠・主張・ `B`・ `Figure`・ `Bottom` を使って必要な関係を表します。
- 全論文の全ページ精読、全図・全パネル精査、全図切り抜き、全値転記は要件にしません。現在の問いと主張への影響に応じて確認します。
- RAG、特定論文・図番号・方式、13〜15枚、既存runの章順を汎用規則にしません。中心比較の再確認によって、採用・不採用・配置を本人が判断します。
- 未解決の原典不一致を必ず解明すること、新規実験、現在価格や総運用費の測定、PPTX/PDFの制作・投影検査を詳細プロットの終了条件に追加しません。残る不確実性と後工程は区別します。
- レビュー指摘すべてを同じ重大度で規則化しません。Run 2の一覧の旧分類やRun 3の局所参照など、終了を妨げない残余を全体再設計の理由にはしません。

説明用再構成と原図の誤同定を解消したことは、再構成の使用許可とは別です。[独立した契約境界レビュー](reviews/contract-boundary-review.md)は、Run 1・3のSelf-Route紹介ページの自作フローが、固定版・現行の[再構成契約](../../references/reconstruction-review.md)による文献紹介の再構成禁止に該当し、現案のままG5で実装できないと判断しました。今回の終了承認は構成・論証の評価に限り、全制作契約への適合や当該図の使用許可を含みません。手法の本文説明と原Fig.1によって中心論証は成立するため、追加のLuna往復は評価終了の必須条件にしません。制作へ進む場合は、当該視覚計画をG4-Vで局所修正してからG5へ渡します。この許可範囲は改訂していません。

## 確認範囲と未検証事項

改訂後の見出し、ローカル参照リンク、変更範囲、既存定義との重複・整合を確認しました。Pythonによる4ファイルの確認では、ローカル参照74件のファイル・アンカー欠落と見出し重複はいずれも0件でした。`research-slide-writing.md` は内容を変更せず、既存説明を参照します。機械契約やスクリプトの変更はありません。

各runの壁打ち成功は、固定した旧スキルに追加の問い返しを与えた結果です。**今回の改訂だけで初回の生成品質が改善するかは未検証**であり、改善済みの3件を新スキルの効果として数えません。同様の問いに加えて別分野の新規課題でも、中心比較の確定と過剰な記録負担の有無を次回の評価観点とします。
