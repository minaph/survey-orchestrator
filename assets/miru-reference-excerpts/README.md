# 提供資料からの図抜粋

この15件のPNGは、ユーザー提供の`tmp/MIRU2026_tutorial_share.pdf`「三次元データ処理の動向」から、設計例の説明に必要な図領域だけを矩形で切り抜いたものです。原図の再描画、数値の再集計、PDF全頁の複製は行っていません。`survey-slide-templates.html`と一緒に保持してください。

直接出所は提供PDFの頁です。HTMLの書誌は資料に記載された論文名を示し、原典からの直接取得・図番号の確認・科学的主張の独立検証を意味しません。資料の説明・評価と今回の整理を区別し、図の切り抜きでも軸、凡例、条件、比較ラベルを保ちます。

`provenance.json`はPDFのSHA-256、頁寸法、切り抜き頁と120 dpi換算の矩形`[x, y, width, height]`（左上の座標と幅・高さ。右端・下端の座標ではありません）、PNGの同一性を記録します。実際のレンダリングは180 dpiです。これは分析用参考例の最小来歴で、実際の研究発表を制作するための原典照合記録ではありません。
