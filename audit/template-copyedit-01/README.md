# スライド文言と参照文書の整理

ユーザー指定に従いSubworkerを使わず親が実装しました。修正後に `request_user_input_async` で次の依頼を尋ね、その後に独立コンテキストのGPT-6.1 Sol / high Reviewerを非同期で起動しています。

## 対応した変更

| 対象 | 修正と判断 |
| --- | --- |
| S01 | 問いの重複を除き、題名はページの役割を示す表現へ変更。「分けて読む」は、短期課題で再開時間、生活場面で負担を調べる説明へ具体化。秒と負担尺度を直接比較する表現も避けた |
| S02 | 題名を「本プレゼンテーションの流れ」へ変更。未導入の抽象語の列挙をやめ、項目の説明を対象と操作に即して具体化 |
| S03 | 「通知のタイミングと量を区別する」へ変更。共通修飾語の反復を整理し、量を一定期間内の提示回数として明示 |
| S06 | 「通知支援研究の概観」へ変更。セルに比較操作、指標、代表研究を補い、「分類範囲・集計規則」を図の直下へ移動。架空設定・既存件数を保持 |
| S13 | 「本プレゼンテーションの限界」へ変更。次の判断列を除き三列に整理。下部で成人の提示時点を比較する条件・指標を整理した意義を示し、年齢内訳などの限界と照合 |
| S16 | 題名を「参考文献」、隣接案内を「関連資料」へ変更。出典確認の機能を過剰な主張にせず、制作指示をスライド外へ移動 |

`references/` は調査・モデリング、構成・デザイン、執筆、制作・検査、進行管理の五分類へ整理しました。環境・配布手順は `docs/` に移し、現行リンクとビルド対象を更新しています。過去評価のsnapshot・結果は変更していません。

執筆スキルは `skills/evidence-based-writing` の固定コミットから同梱します。新たな[表現事例](../../references/writing/expression-alternatives.md)、[修飾・限定の運用](../../references/writing/modifiers-and-scope.md)、[文書機能](../../references/writing/document-functions.md)を追加し、SKILL・RRM・プロット・執筆手順から参照します。外部価値として伝える中心的な知見を少数に絞り、案内・説明・根拠確認の内部的な役割で支える方針です。

## 語句単位での判断例

「通知のタイミングと、通知の量」の二つの名詞には、同じ「通知の」が係ります。共通する修飾を一度にし、概念差を示す述語「区別する」を選びました。一方、対象が異なる研究名や、意味を変える「成人」「短期」「採用12研究」は省略しません。S06の限定は分類図を修飾するため直下に、S13の限界は意義の成立範囲を示すため同じページ内に置きました。

これは新ガイドを今回の制作に適用した記録です。全語句の必須台帳や禁止語の機械置換は追加していません。
