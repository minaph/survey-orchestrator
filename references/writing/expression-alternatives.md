# 曖昧な表現と代替候補

執筆・推敲時に、述語が何を指すか、修飾語がどの区別を加えるかを確認するための事例集です。[同梱の執筆スキル](../../skills/evidence-based-writing/SKILL.md)の寄与・関係・範囲・用語・処理負荷に従い、意図を確定してから候補を選びます。禁止語の一括置換には使いません。

| 避けたい使い方 | 曖昧になる点 | 意図に応じて検討する表現 |
| --- | --- | --- |
| 「短期の作業再開と生活場面の負担を分けて読む」 | 対象の区別、別集計、尺度の違い、読解順序のどれかが不明 | 概念なら「作業再開時間と生活場面の負担を区別する」。分析なら「再開時間と負担尺度を別々に集計する」。比較なら「各場面で測定した結果を比較する」 |
| 「通知のタイミングと、通知の量を分ける」 | 分類・分割・操作のいずれかが不明。同じ修飾語の反復もある | 「通知のタイミングと量を区別する」。操作なら「提示時点を変え、回数を一定に保つ」 |
| 「比較条件をそろえる」だけで終える | 共通化する属性が不明 | 「同じ課題・指標の研究を比較する」「異なる測定尺度は別々に示す」など、実際に行う判断を書く |
| 目次で「定義から比較へ、条件付きの結論へ」 | 未導入の抽象語が発表内容の代わりになっている | 「本プレゼンテーションの流れ」「発表の目次」。項目には読者が扱う対象や問いを書く |
| 参考文献の題名で「問いに応じて根拠へ戻れるようにする」 | ページの機能を長い主張として説明している | 「参考文献」。詳細な導線があるなら小見出しを「関連資料」「付録」とする |
| 見出し・大見出し・下端で同じ問いや結論を反復する | どの文が新しい情報か分かりにくい | 題名で役割、本文で問いや根拠、下端で必要な範囲を示す。追加情報のない文は統合する |

「図を二枚に分ける」「参加者を二群に分ける」のように、分割対象と操作が明確なら「分ける」を使えます。概念差を述べる場面では「区別する」、分類なら「分類する」、別集計なら「別々に集計する」を候補にし、元の命題を強めないことを確認します。

新たな事例は、同じ問題を既存行で説明できない場合だけ追加します。特定ページの修正履歴は案件の制作メモへ置き、ここには再利用できる曖昧さと判断の違いを残します。修飾・限定の具体的な作業は[語句単位の推敲](modifiers-and-scope.md)に従います。
