# 文書・スライドの機能と調査の意義

[RRM](../research/rrm.md)の六観点は、研究の意味を読み解くための観点です。要約・方法・参考文献などの文書機能やページ数に一対一で割り当てるものではありません。文書機能は、読者がいま何を理解・確認できるようにするかを整理するために使います。

## 一般的な論文の機能

以下は構成を読むための整理です。分野や論文形式によって統合・省略・順序変更があり、同じ見出しでも実際の内容を確認します。

| 部分 | 文書内の機能 | 主に確認するRRMの関係 | 発表での使い方 |
| --- | --- | --- | --- |
| 要約 | 問い・方法・主要結果・結論の範囲を圧縮して伝える | 対象、操作、結果、境界 | 冒頭の概要。本文で示す根拠と整合させる |
| 導入・目的 | 問題、調べる理由、問い、対象を定める | 位置づけ、対象の同定 | 「調査の問いと対象範囲」などで入口を作る |
| 先行研究 | 既存の知見と今回の位置・比較対象を示す | 位置づけ、対象の同定、統合 | 「通知支援研究の概観」などで扱う研究の全体像を示す |
| 手法 | 対象・手順・操作・測定・分析方法を説明する | 操作化、対象の同定 | 調査手順や紹介研究の仕組みを具体化する |
| 結果 | 観察・推定・論証された内容を示す | 結果の確認 | 図表の差や傾向を、条件・単位とともに説明する |
| 分析 | 比較や分解から結果の関係を検討する | 操作化、結果の確認 | 比較軸、対象、分析上の追加判断を明示する |
| 考察 | 結果の解釈、先行研究との関係、限界、含意を検討する | 妥当性と転用、統合と次の問い | 支持される解釈と未解決事項を区別する |
| 結論 | 問いへの回答と成立範囲を確定する | 統合と次の問い、妥当性と転用 | 発表全体で残す少数の知見・意義を示す |
| 参考文献 | 主張や説明の出所を追跡可能にする | 根拠の所在を支える。六観点そのものではない | 題名は「参考文献」でよい。書誌と本文引用を対応させる |
| 付録 | 本文の理解を支える詳細と再確認手段を提供する | 内容に応じた観点 | 方法詳細、追加結果、全件一覧など、内容を示す見出しを付ける |

目次・節案内は発表の順序と現在位置を示します。「発表の目次」「本プレゼンテーションの流れ」で機能を伝えられます。未導入の抽象語を並べたり、案内機能を新しい学術的主張のように言い換えたりする必要はありません。

## 外部価値と内部価値を区別する

**外部価値**は、発表の外でも読者の理解・判断を変える調査の知見や意義です。**内部価値**は、対象を定義する、研究の全体像を案内する、方法を説明する、根拠へ戻れるようにするなど、その発表を理解・確認するための役割です。二つは優劣や排他的なページ分類ではありません。分類図はまず発表範囲を案内し、その根拠から分野の偏りを主張できる場合には外部価値も担えます。

プロットでは、外部価値として主張する回答を少数に絞り、発表全体の問いと根拠に結びます。固定の件数や新しい必須欄は設けず、既存の全体回答・節の回答で管理します。各ページは、どの回答を支える説明・案内・根拠確認なのかが分かればよく、全ページに独自の外部価値や新規性を要求しません。

内部価値を担うページには、その機能が伝わる平易な見出しを使います。結果・比較・考察のページでは具体的な命題を示します。「参考文献」という見出しは案内として十分ですが、これを調査の学術的な主張として数えることはできません。見出しの短さではなく、ページの役割と内容の一致で判断します。

限界を示すページには、その限界と両立する調査の意義を残します。分類図には対象範囲と集計規則を近接して示します。具体的な語句と配置は[修飾・限定表現の運用](modifiers-and-scope.md)で点検します。
