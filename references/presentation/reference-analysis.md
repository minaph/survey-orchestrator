# 参考物の観察と採用判断

発表例としてPDF、スライド、文書等が与えられた場合に使います。目的は、対象読者・媒体に転用できる伝達上の選択を見つけることです。参考物だけから完全なデザインシステムを自動的に復元するとは扱いません。

## 対象単位と記述の種類

参考物を一件の分析対象とし、ページ・文字ブロック・図形・節間の移行をその部分として観察します。参考物の版と対象箇所が分かるように記録し、観察・解釈・採用判断を分けます。

| 種類 | 内容 | 位置づけ |
|---|---|---|
| 観察 | ページ数、寸法、縦横比、文字ブロック、明示文字サイズ、位置、色、画像・図形数、フッター、節への再入場、文字類似性 | 実物や抽出結果で確認した内容 |
| 解釈 | 配置が反復する理由、強調色の意味、根拠と装飾の区別、節間の接続 | 観察を説明する分析者の判断 |
| 採用判断 | 対象作業に転用する規則と、その適用条件 | 新しい読者・媒体・目的に対する設計判断 |

観察は解釈を制約しますが、解釈を一意に決めません。走査PDF、密度の高い論文、原ファイルがない資料では、未確認事項と確認できない事項を残します。値が取得できないことを、その要素が存在しないことへ置き換えません。参考物の構成・表示上の観察を、対象分野の主張の根拠へ転用しません。

## 分析と採用の手順

1. 資料種別、想定読者、媒体、ページ数、寸法、縦横比を確認します。
2. 文字ブロック、明示文字サイズ、余白、色、画像・図形数、ページ番号、出典フッター頻度を、ツールが信頼できる範囲で計測します。
3. 全ページの一覧画像を作り、冒頭、目次、方法、定義、根拠、移行、統合、限界、結論、参考文献の代表ページを読書時の大きさで確認します。
4. 構成の流れ、進行速度、局所反復、節の位置づけ、主張と図の関係、引用位置、余白、図の表現規則を解釈します。計測値と区別し、対応する観察を示します。一研究の概念・方法・結果・別能力・限界を扱う連続区間と、研究群を比較する共通軸も確認します。
5. 転用できる規則、参考物固有の値、権利保護された内容、元の読者・媒体に依存する選択を分け、採用範囲を判断します。
6. 不確実性と資料だけでは分からない事項を残します。走査PDFや論文に記されていないスライド制作規則を推定で確定しません。

構成の比較にプロットを使う場合は、[参考物への適用](storyline-plot.md#参考物への適用と改訂)へ従います。観察した参考物のページ順を、対象資料の固定テンプレートにしません。

## 研究紹介の内容を読む

密度は、図数、文字数、占有率だけでは判断しません。読者が何の問題を扱う研究か、既存研究から何を変えたか、方法が結果へどうつながるか、何とどの条件で比べたか、何を評価でき何を結論できないかを読み取れるかを確認します。図の候補には異なる役割を持つ複数図・図内パネルを含め、単一の大きな原図枠だけを研究紹介の既定形にはしません。

- 方法図と結果図は、入力・条件・出力の関係を本文で結びます。二つの図を置くだけではその関係の説明になりません。
- 複数研究は、入力、前提、表現、機構、評価条件、限界など、読者の問いに必要な共通軸を揃えます。機構の対照は、同一条件の性能対決とは限りません。
- 成功例、失敗例、アブレーション、内部分析は、どの主張を支持し、どこで解釈を制約するかを述べます。一例や定性的な外観を全体性能の証明にしません。
- 一つの読解作業を、一研究一頁や一図一頁という制約にしません。連続頁で方法、結果、別能力を掘り下げたり、一頁で複数図を同じ比較軸に接続したりできます。
- 文章のみの頁も、機構差・成果と限界・次の問いを明確に示せば論旨を担います。図を増やすことを内容の充実と同一視しません。

提供スライドから抜粋した図の直接出所は、そのスライドPDFの頁です。そこに記載された論文名、講演者の説明・評価、今回の分析を分けます。原論文と照合していない図番号、実験条件、元の掲載場所を推測で補いません。原典未照合などの分析範囲は作例外側に記し、図に近い出所表示と、読者向けの具体的な研究説明を両立します。原典を取得した後は、[図抽出](../production/figure-extraction.md)の経路で照合できます。

今回の提供資料については[MIRUプロファイル](miru-style-profile.md)に、資料の同一性、確認頁、全体の論旨、代表頁と局所区間、採用・不採用の判断を記録しています。特定の図数・一頁の密度・資料のレイアウトを全分野の固定基準へ移しません。

## プロファイルへの記録

コンパクトなMarkdownで、次の区分を表または見出しとして記述できます。定義・手順と、実際に観察した参考物の記録は分けます。

```text
観察した計測値
解釈した設計上の選択
転用する規則と適用条件
参考物固有の既定値
転用しない内容・権利保護された内容
未決の問い
```

自動化する場合も`observations`と`profile`を異なる種類として保持します。ファイルを二つに分けるかは任意です。具体的な参照候補として[MIRUプロファイル](miru-style-profile.md)がありますが、記載された選択が与えられた実物で確認できるかを確かめて採用します。
