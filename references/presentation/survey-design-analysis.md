# サーベイ発表のデザイン分析

## 目的と適用範囲

この文書は、大規模な文献調査で、読者が問い、研究間の違い、根拠、結論の限界を追えるように、情報の優先順位と配置を決めるために使います。`cross-media-design-decision-support` の形成的デザインを、発表スライドとその配布版へ適用したものです。新しい調査モデルや審査工程は追加しません。

G0で読者と用途を定め、G4-Pで内容と図の関係を検討し、必要ならG4-PDの既存メモへ配置判断を残します。G5で制作し、G6で実物を確認します。[プロット](storyline-plot.md)、[制作契約](../production/presentation-build-contract.md)、[レビュー基準](../workflow/review-rubric.md)が定める責任と状態を引き続き使います。

ここにある型や事例は、設計を比較するための候補です。特定のテンプレートを使ったこと、図の数、余白の割合、文字数だけで品質を判定しません。テンプレートの例示値を実際の研究結果として使わないでください。

## 既存の分析を補う箇所

| 分析の観点 | 既存文書が扱う内容 | この増補で明確にする判断 |
| --- | --- | --- |
| 読者・問い・媒体 | G0のタスク設定、プロットの中心質問と回答 | 会場で聞く人と配布版を単独で読む人について、知識・読む時間・必要な説明がどう異なるか |
| 情報の主従 | 一枚の認知上の役割、本文と図の役割分担 | 最初に見てほしいもの、主根拠、補足、参照情報の順と、画面上の大きさ・位置の対応 |
| 空間配分 | 制作契約の余白・可読性・縮小禁止 | 根拠を追加する、説明を拡大する、表や図へ変える、空けておく、という四案の比較 |
| 図表の意味 | 原図取得、形式別契約、原資料との対応 | 読者の比較・探索・理解の目的に合う型の選択と、型を使わない判断 |
| 色・線・書体 | 表示確認、選んだプロファイルの役割 | 同じ意味を同じ表現へ対応させ、色以外にも名称・位置・線種などの手掛かりを持たせる |
| 派生版 | G6の実表示・文字・出典確認 | 投影版、配布版、HTML作例で密度や操作を変えても、結論・条件・原資料への帰属を保つ |

表は設計上の確認箇所を整理したものであり、既存の実案件で全て実施済みだったという主張ではありません。個別案件では、対象の版と確認した表示を特定します。

## 配置を決める前の分析

### 誰が、何を理解するために見るか

想定する聴衆の知識、投影か配布か、発表時間、途中から見る可能性、最終的に区別してほしい対象を確認します。冒頭の問いと最後の回答を一文ずつ書き、資料が扱わない範囲も示します。既存の `review_concept` やプロットに分かる形で書いてあれば、別の設計台帳へ複製しません。

大規模サーベイでは、全論文の詳細を同じ重みで話すと比較の軸が見えなくなります。主張を説明する中核研究、反証・境界例、集合の傾向を示す研究、詳しく読むための参考文献を、その役割に応じて配分します。採用件数をそのままスライドの配分や根拠の強さへ変換しません。

### 役割に応じて説明の密度を決める

| ページの役割 | 読者が理解・判断できるようにする内容 | 不足の症状 |
| --- | --- | --- |
| 概要 | 範囲、共通分類、主な違い、詳説する研究の位置 | 論文名の一覧から分類の意味や取り上げる理由が分からない |
| 橋渡し | ここまでの回答、残る問題、次の比較を行う理由 | 短い見出しを置くだけで節の論証が接続しない |
| 研究詳説 | 問いと対象・条件、方法の要点、論文の実図、結果の読み取り、評価と限界。必要なら連続ページで説明する | 原図の大きな枠と一言だけで、何を行い何が観察されたか分からない |
| 横断比較 | 共通の問いと比較軸、複数研究の方法・結果の違い、比較できる条件と留保 | 複数図を並べても、共通点・相違点や比較できない部分が分からない |
| 評価と統合 | 根拠が支える回答、競合説明・反証、未解決事項、適用できる範囲と含意 | 「有望」「重要」などの評価が、図と結果から導かれていない |

これはページの役割を選ぶための目安であり、新しい行種別、固定順序、必須フィールドではありません。各ページに研究情報をすべて載せる必要はありませんが、中核研究の説明を担う根拠ブロックでは必要な関係を一続きで理解できるようにします。タイトルと一言、大きな余白で十分なのは、その役割を果たせる場合です。根拠ページで条件・方法・結果・比較評価が欠けていれば、文字が少なく整っていても説明は未完成です。

### 参考PDFから採用する構成上の知見

提供された `tmp/MIRU2026_tutorial_share.pdf` では、p51が複数論文の方法要約と原図を同時に対比し、p93が複数モデル・条件の結果図と観察の要約・留保を併記しています。この観察から、複数図が一つの比較を担えること、評価には実図の読み取りと限定が必要なことを採用します。ページ別の観察と採用判断の正本は[スタイルプロファイル](miru-style-profile.md)に置きます。

提供PDFを使った分析例は、そのPDF上の構成・図・出典表示を確認した範囲で評価します。掲載された専門的主張を独立に検証した扱いにはしませんが、一次論文へ戻っていないことだけで構成の分析例を未完成とも扱いません。実案件で研究の結果や評価を採用する場合は、各図の帰属・条件・意味を一次論文で確認します。参照資料の文字の小ささや出典配置をそのまま模倣せず、図の数・面積・ページ数を普遍的な合否値にせず、今回の問いに答える説明へ転用します。

### 最初に見るものと、その根拠を決める

一枚の主要メッセージ、主根拠、解釈・比較、補足・出典を区別します。主根拠に最も読み取りやすい領域を与え、タイトル、図内ラベル、境界の注記がその関係を説明するようにします。境界が主張の意味を変える場合は、小さな出典欄へ追いやりません。

均等な枠を繰り返すのは、同じ変数・条件・問いを比較するために必要な場合です。重要度の異なる主張、例、注記を同じ大きさのカードへ入れると、その違いが伝わりにくくなります。枠・背景・罫線は、囲む対象や関係を説明できるものだけ使います。

### 空いている領域の使い方を比較する

| 選択肢 | 選ぶ理由の例 | 見送る理由の例 |
| --- | --- | --- |
| 根拠のある情報を足す | 比較条件や反証が欠けており、追加で結論の範囲が分かる | 出典がない、既存の説明と同じ、主張に関係しない |
| 既存の説明を読みやすくする | 原図の軸・条件・凡例を拡大すると関係を観察できる | 拡大しても主張と図の関係が説明できない |
| 表や図へ組み替える | 同じ軸の比較、位置関係、順序が文章より明確になる | 表現形式を変えることで比較条件や不確実性が消える |
| 余白を保つ | 主根拠の観察、まとまりの分離、次の問いへの間に役立つ | 方法や結果が欠けていることを余白で隠す |

追加を選ぶときは、出典箇所、読者が理解できるようになること、増える留保、置き換わる内容、読む負担を短く説明します。数値を図示するときは、比率等に該当する場合の分母、集計単位、解釈に必要な標本数・尺度、資料・データの版、再集計方法、一般化できる範囲を先に確認します。

### 型・表現・分割を選ぶ

[スライド型の一覧](survey-slide-templates.md)から、答えたい問いに合うものを選びます。テンプレートを埋めるために情報を作らず、根拠が足りなければ検索へ戻る、主張を狭める、文章だけで示す、といった判断をします。

一枚に複数図を置くときは、方法と結果の接続、同条件の結果比較、異なる設計方針、反証と留保など、共同で答える問いを明確にします。原図を個別に保った並置と、要素を改変・共通化した調査独自の再構成を区別し、図ごとの契約とページ対応を残します。本文の論文名だけで帰属が曖昧な場合は、各図の近くに識別できる出典を示します。

配置では、必要な情報を保ったまま、比較の同時性、軸・ラベルの可読性、拡大、連携する詳細ページを検討します。一つの関係を同時に見せる必要があれば一枚に保ち、前提を順に理解する必要があれば連続する複数枚に分けて、比較軸・用語・尺度をそろえます。文字を減らすためだけに、評価の根拠となる条件・方法・結果を除きません。投影では読めない詳細は、参照できる付録や配布版へ移しますが、主張の意味を変える条件や限界は投影版にも残します。RRMの六観点やテンプレートの番号を固定のスライド順にはしません。

文献紹介で原図を使う規則は[再構成レビュー](../production/reconstruction-review.md)に従います。原図を入れる枠は、原図の存在・可読性・利用根拠を検証した証拠にはなりません。調査独自の比較や統合図は、その実際の役割と由来を明示します。

## スライドに適した失敗分析

次の観点から、今回の資料に関わるものだけを選びます。名称を付けるだけで不合格にはせず、表示上の症状、伝達への影響、修正、確認方法を示します。

| 観点 | 確認する症状 | 修正の方向 |
| --- | --- | --- |
| AP-01・AP-05：枠の反復と平坦な階層 | 主根拠・例・注記が同じ重みで見える | 主根拠を拡大し、反復は比較に必要な部分へ限定する |
| AP-04：判断につながらない計数 | 件数や割合の大きな表示から何を判断できるか不明 | 件数の単位・範囲を示し、比較・網羅性の説明へつなぐ |
| AP-06：抽象的な見出し | 対象、何が分かったか、どこまで言えるかが読めない | 具体的な対象と関係を戻し、必要な限定を保持する |
| AP-07：根拠のない図示 | 元の値・適用する分母や尺度・計算方法・版へ戻れない | 出典と再計算を確認し、根拠を超える形をやめる |
| 問いに答える情報の不足 | 根拠ページが題名・一言・図枠だけで、方法と結果の関係や評価理由が分からない | 実図と必要な条件・要約・留保を補い、同時比較と詳細説明の配分を選ぶ |
| 比較条件の省略 | 異なる課題・尺度・データの図を同条件の性能比較として扱う | 条件差を明示し、直接比較できる範囲へ評価を限定する |
| AP-13・AP-15：表現と意味の不一致 | 色だけで群を区別する、同じ色が別の意味になる | 直接ラベル・位置・線種を併用し、役割をそろえる |

静的なスライドにフォーム、フォーカス状態、動画の検査を要求しません。HTML配布版に操作や可変幅の表示がある場合は、その実際の機能について、見出し構造、操作名、キーボード、狭い幅での順序と切れを確認します。投影スライドの固定画面と、周囲の説明文のリフローを混同しません。

## 制作への引き渡しと実物の確認

既存のプロット・変更メモへ、次のうちまだ記録されていない判断を短く残します。

```text
読者・媒体・この場面の問い：
最初に見せる主張と主根拠、その境界：
読む順序と、主要・補足・参照情報の配置：
採用した型と、余白・追加・拡大・分割を選んだ理由：
参照する原図・値・版と、配布版へ移す詳細：
完成後に確認する表示と、未確認の条件：
```

これは思考を助ける記入例です。六項目を追加の必須フィールドにはせず、`review_concept`、`reader_visual_job`、`presenter_note`、既存の出典や境界への参照を再利用します。

完成後は、対象版の全体構成と各スライドを実際に表示し、宣言した優先順と見え方が一致するか、日本語の欠字・切れ・重なり、主根拠と境界、軸・凡例・出典を確認します。配布PDFを作る場合は、そのPDF全ページを別に確認します。HTMLが正しく表示されたことは、投影環境や印刷物、PowerPointでの合格を意味しません。

外部資料の採用箇所と媒体上の限界は[資料対応表](design-resource-map.md)、実際の型と編集可能な作例は[テンプレート集](survey-slide-templates.md)を参照してください。
