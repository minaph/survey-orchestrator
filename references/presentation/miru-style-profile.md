# MIRU資料を参考にする表現プロファイル

与えられたMIRU資料を意図的に発表の参考物として分析する場合に使います。分析手順と観察・解釈・採用判断の区別は[参考物分析](reference-analysis.md)を正本とします。この文書は、進行、位置づけ、引用、図の表現に関する具体的な採用候補を示します。対象資料の固定テンプレートや分野の根拠にはしません。

今回の対象は提供PDF `tmp/MIRU2026_tutorial_share.pdf`、表紙題名「三次元データ処理の動向」、MIRU2026チュートリアル講演2、大阪大学・千葉直也です。PDFは122頁、各頁960×540 pt、16:9です。全頁の文字抽出と、構成・研究紹介・比較・反例・留保に関わる37頁の実画像を確認しました。PDF頁番号で以下を記述します。この一資料の観察をMIRU資料全般の実測値や、読者の理解改善の証拠とは扱いません。

確認した実画像はp.5、10–11、13、21–27、37–38、40、43、50–51、54、67、72–83、91、93、103–104、113–114です。本文や図が引用する原論文との独立照合、講演時の口頭説明、動画やアニメーションの動きは未確認です。原論文の研究結果と、この講演資料の説明・評価を分けます。

| 範囲 | 資料で観察できる展開 | 転用する判断 |
|---|---|---|

| p.65–93 | 計測の学習化からFeed-Forward再構成、DUSt3R/VGGT、動的拡張、構造vsデータ、内部分析へ | 出力例・方法の統合・内部機序の検証を別の問いとして扱う |
| p.95–113 | 3D生成から生成と再構成の融合、言語と意味、LLM・QA・強化学習へ | 隣接分野との接続は入力・出力・条件・役割の変化で説明する |
| p.114–122 | 最後に離散vs連続、陽な幾何vsデータからの獲得、決定的再構成vs不確かさ・生成という軸で組み直す。未扱い範囲とテーマ別の文献を示す | 結論を方法名の再列挙で終えず、読者が比較に戻れる軸と支持範囲を残す |

## 内容の密度を生む代表ページ

密度は、文字や図の面積ではなく、読者が方法・結果・比較・評価・境界の関係を読み取れるかで判断します。以下の図数は実画像から確認した局所的な構成であり、PDF内の画像オブジェクト数を数えた値ではありません。

| 頁・区間 | 実画像で確認した内容 | 採用する型と境界 |
|---|---|---|
| p.10–11 | 同じ点群処理の説明を保ち、下線を付ける研究と下半分の図群・下端書誌を切り替える。p.10は集合集約・近傍処理、p.11は系列化・事前学習の図 | 局所反復では比較枠を保ち、注目する機構を移す。全章を同じ配置で反復する規則にはしない |
| p.21–25 | DeepSDFを概念、単一／複数形状モデル、ネットワーク、既存手法との出力比較、形状補間へ展開。p.24の再構成とp.25の補間は別の能力 | 一研究を一頁に閉じ込めない。方法・結果・別能力を連続して読む。一図の外観を全データの優位へ一般化しない |
| p.13 | 設計vsデータの争点、計算量とデータ量の二つの結果グラフ、データ効率・拡張・容量・対称性破りの評価文 | 比較条件を先に分け、局所的な設計上の利点と全体傾向を両方残す。帯の意味や試行条件は原典確認なしに補わない |
| p.27、37、43 | 直前の達成を要約し、表面モデルの限界、計算コスト、光線積分の遅さなどを次の方法の必要性へつなぐ | 「成果→残る問題→次の問い」を節間の橋にする。図のない文章頁も論旨を担う |
| p.50–51 | 表面を意識したGaussian表現、三角形集合と連結メッシュの選択を説明。p.51は式・描画の挙動と頂点共有の対照を並べる | 複数研究を表現・機構の差で比較する。横並びは性能対決とは限らない。p.50の本文はSuGaR/2DGSだが下端書誌はSuGaRのみで、図を2DGSへ推定帰属させない |
| p.54 | 訓練／テスト視点のGTと予測を四画像で対置し、Shape-Radiance Ambiguityの図と幾何の正しさへの注意を加える | 成功例と反例から、評価指標が保証しないことを説明する。表示PSNRを全体平均へ読み替えない |
| p.67 | 形状事前へのショートカットを診断する深度・誤差の例と、修復手法のモデル図を併置 | 良い外観だけでなく、何を実際に用いて予測したかを評価する。診断と修復を同じ根拠と見なさない |
| p.72–74 | 反復最適化とFeed-Forwardの条件付き長短を述べ、p.73で入力画像数・カメラ情報・出力表現を比較。p.74はSRTの方法図と近傍／遠方出力例 | 研究群の共通点を抽象化した後、入力・条件・機構を具体化する。方法と結果を同じ頁へ置くときは別の役割を担わせる |
| p.75–83 | DUSt3Rを古典的サブ問題の統合、Pointmap、ネットワークへ展開。VGGTをタスク、構造、特徴転用へ。p.82–83は同じ一覧で下線・中心図・引用をDA3からMapAnythingへ切り替える | 基準方法を理解してから派生の差分へ進む。共通の問いを保つ局所反復と、実際に図が支える研究の範囲を明確化する |
| p.91 | MegaSaMの幾何制約を使う方法図と、LVSMの構造を削る方法図を争点の下へ並べる | 何を組み込み、何を学習へ委ねるかを比較する。タスクや条件の異なる二手法の性能順位へ変えない |
| p.93 | VGGT・DA3・DUSt3Rの三列、合成／実データの二行の計六パネル。層別の基礎行列復元の分析と、不可視対応を補完する留保を記す | 複数図を共通軸で配置し、内部表現の検証と出力幾何の正しさを分ける。全景は関係を見るために使い、細部は該当列を拡大する |
| p.103–104 | 観測拘束と事前依存、点推定と可能な解の分布を区別。p.104はGen3R/CUPIDの二経路の方法図を並べる | 融合の共通点と、観測・生成・幾何整合を扱う位置の差を述べる。方法図を性能検証にしない |
| p.113 | 三研究を、検証可能な報酬、2D/3D整合性、中間段階の教師信号として文章のみで要約し、三件の書誌を示す | 図がなくても機構の差が明確なら内容の密度を持てる。図を増やすためだけに説明を置き換えない |

資料は白地、大きな左揃え見出し、黒い本文、要点の太字や赤、下端の書誌・ページ番号を多くの確認頁で使います。細かい図内文字や、動画が埋め込まれていた可能性のある大きな空白は、そのまま転用する理由にはなりません。p.79ではPDF上の図領域が小さく、口頭説明や動画の動きはこのPDFだけから復元できません。

## 今回の主見本への適用

[16型の作例](survey-slide-templates.md)では、8型を実図を読む主見本、8型を構成・集計の架空補助例へ分けます。主見本は方法＋出力、再構成＋補間、機構差、問いの転換、条件別結果、反例、融合の経路、支持範囲を実演します。必要な図領域15件を[HTML](../../assets/survey-slide-templates.html)へ同梱し、122頁全体や長い本文を複製しません。

抜粋の直接出所はこの提供PDFの頁です。資料に記載された論文名は書誌として別に表示し、原典からの直接取得や独立検証を意味させません。最小来歴の[provenance.json](../../assets/miru-reference-excerpts/provenance.json)には提供PDFの同一性、切り抜き頁・矩形、表示用画像を記録します。原典未照合は作例外側で明記し、読者用スライドは方法差・観察箇所・評価を中心に構成します。
